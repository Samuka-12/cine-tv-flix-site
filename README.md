# Cine TV Flix

Arquivos do site de download do aplicativo Android Cine TV Flix.

- `index.html`: página do site.
- `CINE-TV.apk`: instalador Android disponibilizado pelo projeto.

Para visualizar localmente, abra `index.html` em um navegador. O link de download da página aponta para `CINE-TV.apk`.
